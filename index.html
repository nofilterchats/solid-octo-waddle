Private rooms
The chat preview above is a demo only. For real private 1:1 messaging with paying clients, see the two realistic options below.

Fastest, no-code path: after a client pays, manually send them an invite to a private Telegram group or Signal chat created just for the two of you. Free, genuinely private, and requires no development — just a few minutes per new client.

Built-in, more automated path: a real in-app private chat (auto-created per client, tied to their payment) requires a backend with authentication and a database — for example Supabase or Firebase — so that each client can only see their own messages. This is a genuine development project, not a no-code afternoon task; worth planning as a phase 2 once you've validated demand with the simpler path above.
